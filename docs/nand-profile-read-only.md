# Одна проверка NAND после обновления macOS

**Статус: подготовлено, живое чтение не выполнено. Требуется отдельное разрешение владельца.**

Цель — проверить прежний источник температуры SSD на `Mac15,7 / 27.0.1 / 26A434`. Приложение пока разрешает NAND только на `27.0.0 / 26A428`; новая версия остаётся «Нет данных».

Автоматическая проверка разрешений отклонила запуск до создания процесса: после неудачного опыта запрет новых аппаратных проверок был применён и к этому чтению. Подготовка и модельные тесты завершены. Агент выполнит описанное чтение только после отдельного явного разрешения; ввод пароля, Touch ID и перезагрузка для него не нужны.

## Точный объём

1. Агент сверяет хеши всех файлов ниже и отсутствие каталога результата.
2. Один процесс без root проверяет модель, версию и сборку ОС. Несовпадение останавливает его до обращения к датчику.
3. Выполняется максимум пять вызовов существующего `HIDTemperatureReadNAND`, с паузой одну секунду. Читается только `NAND CH0 temp`, `LocationID=TN0n`, класс `AppleEmbeddedNVMeTemperatureSensor`, непосредственный родитель `AppleANS3CGv2Controller`, usage `0xff00/5`. Неоднозначный сервис, отсутствие частного API/события, timestamp старше двух секунд или некорректное число отвергаются. Первое неподходящее чтение завершает серию.
4. Для принятия результата нужны пять конечных чисел −10…125 °C, длительность каждого чтения менее 0.5 с, серия не короче четырёх секунд, неизменный профиль и исходники. Внешний процесс устанавливает timeout 8 с; при его превышении запрашивает завершение дочернего процесса и сохраняет отказ. Планировщик ОС может задержать завершение.
5. В новом каталоге сохраняются `started.json` и `result.json`: профиль, пять температур/кодов/длительностей, UID и хеши. Каталог имеет права `0700`; существующий каталог блокирует запуск. После отказа данные сохраняются, автоматического повторения нет.

Аппаратных записей **0**. Пробник не включает SMC-транспорт, не обращается к helper/XPC/ServiceManagement, не читает root journal, не меняет вентиляторы, установку или фоновые службы. CPU/Metal нагрузки отсутствуют. Содержимое SSD, серийные номера и полный каталог датчиков не собираются. Частный HID API может отказать или зависнуть; это причина внешнего срока ожидания. Результат не подтверждает возврат Auto и не устанавливает температуры CPU/GPU.
